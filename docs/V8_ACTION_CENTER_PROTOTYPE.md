# V8 今日行动中心 Prototype

> 状态：用户已确认，正式 UI 已在本地候选中接入首页、自选与基金详情；“首页 / 选基 / 自选”主导航及隐藏高级路由保持不变。生产持久化与自然 Worker 调度门禁尚未完成，因此仍不代表 v8.0.0 已发布。

## 页面任务

- 对象：每天查看自选与持仓、但不希望先读完一屏指标的个人基金用户。
- 单一任务：在 30 秒内回答“今天有没有需要处理的基金，优先看哪一只，为什么，以及什么会让建议改变”。
- 信息顺序：行动分布 → 优先关注 → 证据与失效条件 → 市场温度与系统状态。

可交互原型：[`docs/prototypes/v8-action-center.html`](prototypes/v8-action-center.html)

## 视觉与结构

原型沿用司南现有“宋代青绿山水 × 安静账本”语言，不引入网络字体。色彩继续使用深松 `#244F3D`、青绿 `#3F765C`、旧金 `#C99A3D`、朱砂 `#D24A3A`、宣纸 `#F8F7F1` 与墨色 `#183229`。

唯一强调元素是“行动罗盘刻度”：优先事项沿一条纵向刻度排列，刻度颜色表达动作性质，顺序表达当天处理优先级。它不是装饰时间线；每个节点都对应一个真实 Decision Snapshot。

## 数据映射

| 原型区域 | V8 数据字段 | 失败关闭规则 |
|---|---|---|
| 动作分布 | `decision.action` | 请求部分失败时只显示已返回数量，并单列异常数 |
| 优先顺序 | action、strength、confidence、position guidance | 缺目标权重时不展示精确金额或精确仓位差 |
| 主要原因 | `reason_codes` + `reasons` | 不让 AI 新增原因或数字 |
| 变化 | `DecisionDiff` | 无上一条快照时显示“首次记录”，不编造变化 |
| 失效条件 | `invalidation_codes` + conditions | 至少显示一条，可展开全部 |
| 数据状态 | `SourceState`、missing/stale fields | stale/unavailable 显式降级，关闭强动作 |
| QDII | target date、market time、coverage、version、sample、MAE/P80/direction | 样本不足或误差高时仅作辅助 |
| 历史结果 | 5/20/60 Outcome | 未成熟显示“等待第 N 个净值观测”，不补 0 |
