# 本机资产与历史共同工作区

本文件说明物理 IndexedDB v5 的候选实现。它不是应用 v9.0.0 发布，也不是后端 schema 版本升级。当前完整手工资产云同步尚未接通，v5 的私人上传与持仓分析入口暂时关闭；不要据本机保存或文件 SHA 解除 `local_pending`。

## 从已有 v4 迁入

1. 在资产页下载“资产历史迁移原文件”。文件包含已采用的完整 v4 工作区，以及 `sinan_manual_assets_v1`、`sinan_snapshots` 两份原文。私人文件只保存在自己的设备。
2. 保留下载文件，选回同一文件并核完整 SHA256。界面列出迁移数量、全部资产 ID 映射和问题；有问题则整批暂停。无法兼容的数据不会被丢弃后冒充成功。
3. 确认后只升级当前已核定 target。普通启动不升级，v3 须先走已有 v3→v4 流程。升级不删除旧 LS 文件，但成功后资产页不再读取或双写它们。
4. 升级成功后用“下载当前资产历史完整备份”导出后来编辑后的完整 v5。升级前文件仅代表升级当时的旧状态，不能代替当前备份。

超长或不合法的旧资产 ID 使用明确显示的 SHA256 映射，原 ID 与原文仍保留；不截断、不猜账户身份。新资产使用新的 `asset:` 键，移出保留 tombstone。

## 中断与未知结果

物理 versionchange 与 strict 初始化是两次提交。前者创建 `portfolio_metadata` 并保存固定 `intent`；后者核完整旧像和原 intent 后写 `current`。正常打开必须恰有这两行，不补缺项。

中断时选回原文件，使用“核对原资产历史升级”。应用由原文件 SHA 重建同一个请求 id/hash，只接受现有物理 v5、原 intent、完整未变旧像，以及空 current 或完全相同的初始 current。缺库、错误请求、额外行、后续编辑均拒绝；不会重建丢库、降级、重新导入或覆盖新数据。

普通资产或历史保存若结果未知，保留本轮原 id/hash，只能手动核最近本机回执；不自动重放。后来的编辑覆盖最近回执后，旧请求保持 unknown。刷新只读当前数据，不证明此前未知请求已经核定。内存中的普通编辑请求标识不保证跨刷新持久。

## 金额与历史口径

- 基金、手工资产和历史共用完整本机前像校验及独立 localVersion/空槽 epoch；这两个计数都不是云 revision 或 HoldingVersion。
- 原历史的 UTC 日期、重复日期、行序、不透明旧 ID、原金额和成本值全部保留。旧手工成本可能只是当时余额代理，不是真实购入成本。
- 新历史称“余额观察”，显式追加，以上海日期标记；不自动覆盖同日记录、不清理超限旧行。明确零份的每个账户仍保留身份，未知份额不能变为零。
- 手工资产没有真实成本输入，观察成本为 null；缺成本不造零收益。余额变化可能包括入金或赎回，不作为现金流调整后的投资收益。
- 单份旧 raw 上限 2 MiB，portfolio 总上限 8 MiB，历史与资产各最多 2,000 条。完整恢复文件共用 24 MiB 上限，升级和编辑前检查完整可导出性；超限须保全原状态并拒绝本次写入。

## 三类文件不同用途

| 文件格式 | 内容与用途 | 不证明的能力 |
| --- | --- | --- |
| `sinan-owner-portfolio-upgrade-1` | 原完整 v4 与两份独立 raw；显式迁移及原升级核对 | 后续编辑的备份、云确认 |
| `sinan-owner-workspace-recovery-2` | 当前完整 v5：基金、portfolio、intent、B、旧档案与最近本机回执 | 丢库恢复器、远端耐久、来源认证 |
| `owner-portfolio-history-export-1` | 查看用历史，保留原日期/数值/标识 | 完整工作区恢复 |

旧 `sinan-owner-workspace-recovery-1` 仍严格只接受 v3/v4，不把缺资产/历史的旧文件标为完整 v5。任何 SHA 均仅用于内容一致性核对。

## 下一实现与发布边界

v4 的完整 B 已保留云端 manual，但从未把 manual 应用到本机 L。因此不能直接打开旧 fund-only planner。下一阶段须显式初始化手工资产共同基线、支持完整 manual 意图和三方 ACK，原包前像同时绑定基金、资产、历史、intent 与新 profile；基金账户更名规则不套到手工资产。历史观察继续按独立留存/导出合同处理。

还需实际浏览器/PWA、多设备、后端受控迁移、跨重启持久化和独立远端恢复证据。代码回退必须保全 v5 数据，不能通过删库恢复旧格式。应用正式版本仍待整个 v9 计划的必要门禁通过后统一更新。
