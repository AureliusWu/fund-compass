# 海外任务与校准评估修复

## 延迟观察的目标日行情

计划任务延迟到美股下一交易日后，实时行情的日期可能已越过当前合法预测的目标日。新增只读日线证据适配器：只有当前官方净值仍满足原 base 日期轴、尚无目标日净值时，才补取缺失的目标日行情。交易所后缀必须来自当前腾讯原文，目标日及紧前交易日的腾讯前复权收盘价必须与 Nasdaq 原始收盘价逐值相等。缺日、复权差异、来源冲突、预算超限等继续保持缺失并记录诊断。

日线证据保留真实日期，明确 `time_precision=date`，不伪造收盘时间。当前观察可以生成新预测；旧失败、旧账本、跨日或人工请求不回填。96 小时新鲜度、20 样本、精确日期配对及模型门槛不变；海外 journal 的四个冻结协议文件不变。

## 校准完成与发布结果分开

工作流使用 `--evaluate-only`。样本和投票等原门槛未通过时，可以明确完成一次“候选拒绝”的评估；同参数候选同样不请求发布。两种完成状态都要求 `publish=false`、`publication_accepted=false`，且不改变 registry 或公开报告。

执行/读取异常、不足样本、非有限或不完整证据仍失败。合格新候选缺少经过认证的私有存储时，继续 `BLOCKED_PRIVATE_SINK_REQUIRED`，不上传私有产物、不晋级 active。CLI 默认行为保持兼容；状态文件和其原子写临时路径不得与默认或实际配置的 registry、公开报告发生路径或文件身份碰撞。

## 验证与交付边界

专属及流水线回归覆盖双源行情、日期轴、防回填、JSON/时间/大小界限、冻结 journal、正常拒绝、合格但受阻候选、隐私守卫和输出路径别名。Windows 无权限创建的真实符号链接用例明确跳过，Linux CI 仍执行这些用例。
